## Dashboard

- Dashboard contains widgets. all widgets are the same size, rectangular blocks.
- Widgets are clear and easy to read.
- User can add a widget clicking an "Add widget" button.
- "Add widget" button opens "Add widget" menu
- User can choose among widgets type and add one
- widget types:
  - Spent today: sum of isFinished lists for today
  - Spent in category for month. User choose category on widget add 
  - Spent in month. Summ of month expanses for all categories in this month
  - Add Purchase. Actin button on widget that leads to ShoppingList view and open add Purchase dialog. manual type.
